# Brief: 11d 2.2 Custom-day refresh through the season engine

Backlog item: `docs/PLAN-gap-backlog-2026-11d.md` 2.2. Read it first.

## Problem

"Refresh prescriptions" on a custom-routine day runs
`WorkoutGenerator.represcribe` (`WorkoutGenerator+Represcribe.swift:32`) into
`makePickedRow` (`WorkoutGenerator.swift:297`) and the legacy
`prescription(for:)` (`WorkoutGenerator+Prescription.swift:203-277`). That
legacy path cuts a set at 55 and at 70 and adds a set to every compound for
advanced users. Every planned lift day is prescribed by
`SportSeasonGenerator.prescribe` (`SportSeasonGenerator.swift:1046`) and
`SetScheme.adjusted` (`SportSeasonModels.swift:244`), which acts at 60 and
adds a set on main lifts only. A refreshed custom day and a planned day
disagree for the same athlete.

## Design (lead decisions, follow them)

1. Add one internal (not private) entry on `SportSeasonGenerator`:
   `static func prescribeRefresh(_ exercise: Exercise, slotIdx: Int, focus: WorkoutFocus, athlete: AthleteState, strategy: GeneratorStrategy) -> GeneratedExercise`.
   It calls the existing private `prescribe(_:demand:rule:...)`, so there is
   one prescription path. No second copy of the scheme logic.
2. Movement: look the exercise id up in `CoachDatabase.shared.sportMovements(sport:)`
   for `athlete.sportSlug` first, then `"general-fitness"`. Use that
   `SportMovement` (protocol fields, catalogReps, primary demand) when found.
   Otherwise build a `SportMovement` from the `Exercise` (isCompound,
   isUnilateral, `catalogReps: exercise.defaultReps`, no protocol, no caution,
   minExperienceRank 0).
3. Demand when the seed has none: from the exercise's movement-pattern
   category (`MovementCategory` in `ExerciseFilters.swift`, reverse map at
   `:218`, patterns via `CoachDatabase`). Push → `.upperPush`, Pull →
   `.upperPull`, Legs → `.legStrength`, Core → `.core`, arms patterns →
   `.arms`. A compound at `slotIdx == 0` whose category is Push, Pull or Legs
   maps to `.upperStrength`, `.pullStrength`, `.legStrength` (the main-lift
   demands, so advanced gets its extra set the same way a planned day does).
   Nothing matches: use the `focus` (push/pull/legs/core) the same way, else
   `.core`. Record the final table in a doc comment.
4. Rule: `PhaseRule.resolve(...)` exactly as `generateSession` calls it
   (`SportSeasonGenerator.swift:26` / `:79`) for the athlete's sport and
   season. No ramp week (refresh has no block position).
5. After `prescribe`: apply readiness and strategy set scaling the way the
   season session applies it after `fitToBudget` (find that code; reuse it,
   do not re-derive), keep the slot-0 compound warm-up ramp
   (`WarmUpSet.standardRamp`, skip when sore, as `makePickedRow` does today),
   and keep the progressive-overload "target: X" note
   (`WorkoutGenerator.progressiveOverloadHint`). Readiness RPE cap stays only
   if the season path applies one; otherwise drop it.
6. `represcribe` `.fullRefresh` builds the `AthleteState` the way
   `generateLift` does (`WorkoutGenerator.swift:106-117`, `AthleteState.from`)
   and calls `prescribeRefresh`. Duration for the estimate: `sets * (45 + rest) + 30`
   per row, as today. `.weightsOnly` unchanged. Identity rules (id, name,
   supersetGroup, merged notes) unchanged.
7. Delete every function that loses its last caller: `makePickedRow`,
   `prescription(for:)`, and whatever under `WorkoutGenerator+Prescription.swift`
   only they reached (`rpeTempoHints`, `capCompoundRPE`, focus bias helpers,
   etc.). Grep each before deleting. Update `WorkoutGeneratorTests.swift:115`
   (calls `prescription(for:)`): delete that test or re-point it at
   `prescribeRefresh` if it tests something the new path still owes.
   Leave the private rest parser at `WorkoutGenerator+Prescription.swift:318`
   alone unless it loses its last caller (11d 2.7 owns it).
8. Correct the "Status 2026-11-10" section of
   `.claude/skills/phase-training-prescription-precedence-and-dual-path/SKILL.md`:
   say the refresh path now goes through `SportSeasonGenerator.prescribeRefresh`
   and the legacy `prescription(for:)` is deleted (date 2026-11-21).
