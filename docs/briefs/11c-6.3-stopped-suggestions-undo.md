# 11c 6.3 Stopped suggestions with undo

Backlog: `docs/PLAN-gap-backlog-2026-11c.md` item 6.3. Builder (Sonnet). Skill to load: none required; read `PhaseTraining/Data/PatternEngine.swift` and `PhaseTraining/Data/PlanStore+Suggestions.swift` first.

## Problem

The weekly check-in's "You keep skipping X" card offers "Stop planning it". Accepting sinks the exercise (`exerciseAffinities[name] = AthleteState.affinitySinkThreshold`, -2) and records `SuggestionDecision(suggestionId: "droppedExercise:<lowercased name>", accepted: true)`. No screen lists these, and the only way back is never shown: Favorites lists score > 0 only.

## Design (decided, do not change)

1. Pure reader in `PatternEngine.swift`, next to `SuggestionDecision`:
   ```swift
   struct StoppedExercise: Hashable { var name: String; var stoppedAt: Date }
   static func stoppedExercises(decisions: [SuggestionDecision], affinities: [String: Int]) -> [StoppedExercise]
   ```
   - Take decisions with `accepted == true` whose id has prefix `"\(SuggestionRule.droppedExercise.rawValue):"`. Subject = the rest of the id (already lowercased).
   - Per subject keep the newest such decision.
   - Keep it only while the exercise is still sunk: `AthleteState.lowercasedAffinities(affinities)[subject] ?? 0 <= AthleteState.affinitySinkThreshold`. An exercise un-sunk any other way drops out.
   - Display name: the raw affinity key matching the subject case-insensitively, else the subject.
   - Sort newest `stoppedAt` first, then name.
2. Undo in `MemoryStore.swift`: `func resumePlanning(_ name: String)` clears every case variant of `name` from `exerciseAffinities` (same fold as `FavoritesEditorSheet.remove`). Nil is "no preference". Leave `suggestionDecisions` alone: the accepted decision keeps the card from returning unless three new drops land after the accept (`PatternEngine.allowed`), which is the right behavior after the user says "keep planning it".
3. UI in `PhaseTraining/Screens/DislikesEditorSheet.swift`: below the avoid list, a section only when the list is non-empty:
   - Header `Text("STOPPED FROM CHECK-IN").styled(.micro).foregroundStyle(Color.ink3)`, same style as "EXERCISES TO AVOID".
   - One row per item: name (`.styled(.body)`, `Color.ink`), a mono line `Stopped <date>` (`.font(.monoXS)`, `Color.ink3`, date as `Text(stoppedAt, format: .dateTime.month(.abbreviated).day())`), and a trailing `Button("Plan it again")` in `Color.accent` calling `store.resumePlanning(name)`. Accessibility label on the button: "Plan \(name) again".
   - A footnote in `.monoXS` `Color.ink3`: "You chose Stop planning it on these in a weekly check-in. Plan it again goes back to no preference."
4. `ProfileScreen+RowSummaries.swift` `dislikesSummary`: count stopped items too, so the row does not read "None" while the sheet holds something. Rule: total = dislikes.count + stopped.count; 0 → "None"; 1 → that one name (dislike or stopped); else "\(total) items".
