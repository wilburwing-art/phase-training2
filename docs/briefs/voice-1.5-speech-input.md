## Types

```swift
/// Why the mic button is off. `message` is the line shown under it.
enum SpeechInputUnavailable: Equatable {
    case microphoneDenied        // "Microphone access is off. Turn it on in Settings > Phase Training."
    case speechDenied            // "Speech recognition is off. Turn it on in Settings > Phase Training."
    case restricted              // "Speech recognition is restricted on this device."
    case onDeviceUnsupported     // "This device can't recognize speech offline, so voice logging is off."
    var message: String { get }
}

enum SpeechAuthorization: Equatable { case notDetermined, granted, denied, restricted }

/// Mic and speech-recognition status, split from the transcriber so tests drive it.
@MainActor protocol SpeechPermissionProviding: AnyObject {
    var microphone: SpeechAuthorization { get }
    var speech: SpeechAuthorization { get }
    func requestMicrophone() async -> SpeechAuthorization
    func requestSpeech() async -> SpeechAuthorization
}

/// One push-to-talk utterance. `start` opens the mic; `finish` stops input and returns the
/// final transcript (nil when nothing was heard); `cancel` drops it.
@MainActor protocol SpeechTranscribing: AnyObject {
    var supportsOnDevice: Bool { get }
    func start(contextualStrings: [String], onPartial: @escaping (String) -> Void) throws
    func finish() async throws -> String?
    func cancel()
}

/// What 2.4 binds to. ObservableObject, @MainActor.
final class SpeechInput: ObservableObject {
    enum State: Equatable { case idle, listening(partial: String), finishing, unavailable(SpeechInputUnavailable) }
    @Published private(set) var state: State
    var micEnabled: Bool { get }             // false only in .unavailable
    init(transcriber: SpeechTranscribing, permissions: SpeechPermissionProviding)
    func refreshAvailability()               // reads current status, no prompt
    func pressDown(exerciseNames: [String]) async   // requests permission if notDetermined, then starts
    func release() async -> String?          // final transcript, trimmed; nil for empty or error
    func cancel()
    static func contextualStrings(exerciseNames: [String]) -> [String]
    static func makeDefault() -> SpeechInput // picks the live transcriber, see below
}
```

Exact names may move if the SDK forces it; record any change.

## Rules

1. **Availability.** Order: restricted (either) -> `.restricted`; mic denied ->
   `.microphoneDenied`; speech denied -> `.speechDenied`; `!supportsOnDevice` ->
   `.onDeviceUnsupported`. `notDetermined` is not unavailable: `pressDown` asks (mic first,
   then speech) and lands on the result. A denial from the prompt sets `.unavailable` and
   never starts the transcriber.
2. **Final-result handling.** `release()` trims whitespace. Empty or whitespace-only -> nil.
   If the transcriber returns nil but a partial arrived, return the last partial (the
   recognizer sometimes drops the final on a short utterance). A thrown error -> nil, state
   back to `.idle`. `release()` while not listening -> nil, no call to `finish`. A second
   `pressDown` while listening is a no-op.
3. **Contextual strings.** Exercise names (deduped, original casing, empties dropped) then
   the command words: same again, done, skip rest, undo, what's next, how many left, RPE,
   kilos, pounds, for, by. Cap at 100 entries (Apple's guidance for `contextualStrings`).
4. **Audio session** (live transcribers only): on start `.playAndRecord`, mode `.default`,
   options `[.allowBluetoothHFP, .duckOthers, .defaultToSpeaker]`; on finish or cancel
   `setActive(false, options: .notifyOthersOnDeactivation)`. If `.allowBluetoothHFP` is
   unavailable below iOS 26 in this SDK, use `.allowBluetooth` there under `#available`.
5. **Live transcribers.**
   - `AnalyzerTranscriber` (`@available(iOS 26, *)`): `SpeechTranscriber` for
     `SpeechTranscriber.supportedLocale(equivalentTo: .current)` with volatile results,
     `SpeechAnalyzer`, an `AVAudioEngine` input tap converted to
     `SpeechAnalyzer.bestAvailableAudioFormat`, contextual strings through
     `AnalysisContext`. `supportsOnDevice` false when no supported locale. If the locale's
     assets are not installed, `makeDefault` falls back to the legacy transcriber rather than
     downloading during a set.
   - `LegacyTranscriber`: `SFSpeechRecognizer(locale: .current)`,
     `SFSpeechAudioBufferRecognitionRequest` with `requiresOnDeviceRecognition = true`,
     `shouldReportPartialResults = true`, `contextualStrings`, `taskHint = .dictation`.
     `supportsOnDevice` = `recognizer?.supportsOnDeviceRecognition == true`.
   - `makeDefault`: iOS 26 with an installed supported locale -> analyzer, else legacy.
   - Audio never leaves the device: no server fallback path in either.
6. **Usage strings** (Project.yml, reviewer-facing, name the behavior):
   - `NSMicrophoneUsageDescription`: "Only while you hold the mic button during a workout,
     PhaseTraining listens so you can log a set or control the rest timer by voice, like
     \"185 for 5\" or \"skip rest\". It never listens in the background."
   - `NSSpeechRecognitionUsageDescription`: "PhaseTraining turns what you say while holding
     the mic button into a logged set or a timer command. Recognition runs on your device and
     the audio is never uploaded or stored."
