## Problem

`AuthoredRoutineSelector.select` (`PhaseTraining/Data/AuthoredRoutine.swift:134`)
rotates `ids[sessionIndex % count]` over every viable routine with no regard to
length. `AuthoredRoutine.workout` only trims when a same-day time chip is set.
A 75-minute budget can get a 21-minute routine while a longer one sits in the
same pool. Measured pools (week-1 estimate, sets x 90 s or the row's leading
minutes): cycling maintenance 12, 58, 55, 46; kayaking build 12, 33, 34;
general-fitness base 18, 33. Most sports hold one or two routines, so ranking
changes the pick only where a pool spreads.

## Design (lead's ruling, implement as written)

1. `AuthoredRoutine.estimatedSeconds(sets:reps:)` static: the body of the
   current `estimatedSeconds(_ ex:)`, which now calls it. No behaviour change.
2. `AuthoredRoutineSelector.estimatedMinutes(forRoutineId:excluded:allowed:preferences:experience:planWeek:) -> Int`:
   sum of `estimatedSeconds(sets: row.sets(forWeek:) ?? 3, reps: row.reps(forWeek:) ?? "8-12")`
   over `AuthoredRoutine.resolvedRows(...)`, divided by 60. Same defaults as
   `workout` uses (`AuthoredRoutine.swift:374`, `:396`), so the selector and
   the served session agree.
3. Split `select` into `candidates(...) -> [Int]` (the current body up to the
   `guard !ids.isEmpty`, same tiers, internal so tests read it) and `select`.
4. `static let durationTolerance = 10` (minutes) and
   `static func fitting(_ ids: [Int], budget: Int, minutes: (Int) -> Int) -> [Int]`:
   gap = `abs(minutes(id) - budget)`; keep ids whose gap is at most
   `bestGap + durationTolerance`, in their original (id ASC) order. Empty in,
   empty out. Rotation then runs over the kept ids, so several routines that
   fit still rotate across the week.
5. `select` gains `sessionMinutes: Int? = nil` and `planWeek: Int? = nil`.
   nil `sessionMinutes` keeps today's pick exactly (every existing test call).
   With a value and more than one candidate, rotate over `fitting(...)`.
6. `WorkoutGenerator.swift:188` passes
   `sessionMinutes: recovery.timeBudget ?? memory.sessionMinutes` and
   `planWeek: memory.weeksInCurrentPhase ?? 1`. Leave the second call at
   `:208` alone: it only tests for nil, and ranking never turns a non-empty
   pool empty.
7. Update the selector's doc comment and the skill's "Multiple matches rotate"
   line in `.claude/skills/phase-training-authored-routine-serving/SKILL.md`.
