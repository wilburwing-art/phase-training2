## Design (lead)

### What a record holds

Written once per accepted check-in in `WeeklyCheckInFlow.accept()`
(`WeeklyCheckInFlow.swift:284-305`):
- `weekStart`: the start of the week the check-in planned (next week at the
  time of writing). Label rows "Week of <MMM d>".
- `intent`: chip labels joined by ", " then free text, joined by " · ". Nil
  when empty.
- `lastWeekRating`: "too_easy" | "right" | "too_hard" | nil.
- `notes`: "worked: X · didn't: Y", either part optional. Nil when empty.
Pruned to 26 weeks on write.

Show the stored strings verbatim. Do not re-parse intent or notes.

### Pure model, new file `PhaseTraining/Data/CheckInHistory.swift`

```swift
struct CheckInHistoryRow: Hashable, Identifiable {
    let id: UUID
    let weekStart: Date
    let intent: String?        // nil when nil or whitespace-only
    let rating: String?        // raw value, nil when nil or empty
    let notes: String?         // nil when nil or whitespace-only
}

enum CheckInHistory {
    /// Newest weekStart first. Ties keep the later-appended record first.
    static func rows(_ checkIns: [WeeklyCheckIn]) -> [CheckInHistoryRow]
    /// Spoken rating: "too easy" | "about right" | "too hard" | nil for unknown/nil.
    static func spokenRating(_ raw: String?) -> String?
    /// One VoiceOver sentence per row, e.g.
    /// "Week of Nov 16. Last week too hard. Intent: Deload. Notes: worked: hills."
    /// Skips parts that are nil. Takes a calendar/locale-free formatter input
    /// via `dateText` closure so tests stay deterministic.
    static func spoken(_ row: CheckInHistoryRow, dateText: (Date) -> String) -> String
}
```
