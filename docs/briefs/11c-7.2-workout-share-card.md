# 11c 7.2 Workout summary share card

Backlog item: `docs/PLAN-gap-backlog-2026-11c.md` 7.2. Builder: `builder` (Sonnet). Slot A.

## Problem

The Complete screen has no way to share a finished workout. Rival apps ship a share image. This one must stay local: no account, no network, no user name or body data on the card.

## Files to touch

1. New `PhaseTraining/Components/WorkoutShareCard.swift`:
   - `struct WorkoutShareSummary: Equatable`, a pure value with a `static func make(...)` builder. Inputs: session name, session date (`loggedFor?.start ?? startTime`), elapsed seconds, done set count, working volume (Double) and `usesImperial`, PRs as `[(name: String, diff: Double, unit: String)]` (or a small public struct), and the done exercises (name plus done set count). Output fields: `title`, `dateLine` ("Thu, Nov 27"), `durationLine` (reuse `CompleteScreen.formatElapsed`), `setsLine` ("18 sets"; "1 set"), `volumeLine` ("12,450 lb" / "5,640 kg", nil when volume is 0), `prLines` ("Bench Press +10 lbs", diff formatted with no trailing .0), `exerciseLines` (top 6 done exercises in session order as "Bench Press · 3 sets", plus "+N more" when over 6), and `shareText`: a plain-text version of the same lines joined by newlines (title, date, duration · sets · volume, PR lines, exercise lines), ending with "Logged in Phase". Exercises with no done set are left out.
   - `struct WorkoutShareCardView: View` rendering the summary at a fixed 1080x1350 logical size scaled down: lay it out at 360x450 points and render at `scale = 3`. Dark background (`Color.bg`), use the app's text styles (`.styled(.micro)`, `.styled(.displayM)` etc. as on CompleteScreen), accent for PR lines, a small `KettleView(pose: .flex)` is fine if it renders under ImageRenderer, else leave it out and note it. No text may truncate for the six-exercise case: use `lineLimit(1)` plus `minimumScaleFactor` on long names.
   - `enum WorkoutShareCard { @MainActor static func image(for: WorkoutShareSummary) -> UIImage? }` via `ImageRenderer` (see `MuscleChipGeneratorView.swift:216` for the pattern). Set `renderer.scale = 3`. Apply `.environment(\.colorScheme, .dark)`.
2. `PhaseTraining/Screens/CompleteScreen.swift`:
   - A "Share workout" row button (style like `feedbackButton`: Inter 13 medium, accent, with `square.and.arrow.up` icon) placed after the PR block and before `exerciseSummary`, `accessibilityIdentifier("complete-share")`. Hidden when no set is done or after discard.
   - On tap: build the summary from the same values the screen shows (`elapsedSeconds`, `stats.doneSets`, `session.workingVolume(usesImperial:)`, `prs`), render the image, and present `.sheet` with `ShareSheet(items: [image, summary.shareText])` (image first; if rendering returns nil, share the text alone).
   - `PRItem` stays private; map it into the summary's PR input.
3. New `PhaseTrainingTests/WorkoutShareSummaryTests.swift`: cases for set pluralisation, volume nil at 0 and formatted with grouping in lb and kg, PR diff formatting (10 → "+10", 2.5 → "+2.5"), exercises without done sets dropped, the "+N more" cap at 6, `shareText` holds title, PR line and "Logged in Phase", and `WorkoutShareCard.image` returns a non-nil image of 1080x1350 pixels.
