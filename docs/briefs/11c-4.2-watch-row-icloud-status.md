## Design

1. **Watch presence flag.** In `WatchSyncCoordinator`:
   - `static let appInstalledKey = "watch.appInstalled"`. No `pt_` prefix on purpose: it is device state, so erase must not clear it and a backup must not carry it to another phone.
   - `private func recordWatchState(_ wc: WCSession)` sets `defaults.set(wc.activationState == .activated && wc.isPaired && wc.isWatchAppInstalled, forKey: Self.appInstalledKey)`. Call it on the main queue from `activationDidCompleteWith` and `sessionWatchStateDidChange` (both already hop to main; add the call inside those blocks). `sessionDidDeactivate` sets it false.
2. **Profile Apple Watch row.** `@AppStorage(WatchSyncCoordinator.appInstalledKey) private var watchAppInstalled = false` in `ProfileScreen`. When true, a `SettingsRow(label: "Apple Watch", value: "App installed", icon: "applewatch")` placed directly above the Data row, identifier `profile-watch-row`. Action: an `.alert("Apple Watch", ...)` with message "Start today's workout on the watch, or start it here and mark sets on either. Sets sync both ways." and an OK button.
3. **Log hint.** In `LogScreen.titleBlock`, when the same `@AppStorage` flag is true, one line under the logged-for button: `Text("Also on your Apple Watch. Sets you mark there land here.")`, `.font(.monoXS)`, `Color.ink3`, identifier `log-watch-hint`. No dismiss control.
4. **iCloud state in the Data row.**
   - `CloudBackup.isSignedIn(token: () -> Any? = { FileManager.default.ubiquityIdentityToken }) -> Bool` returns `token() != nil`. Cheap and main-thread safe.
   - `BackupCoordinator`: `@Published private(set) var lastICloudWrite: Date?` and `@Published private(set) var iCloudSignedIn: Bool`, both loaded in `init(defaults:signedIn:)` (`signedIn: Bool = CloudBackup.isSignedIn()`). Add `func refreshCloudStatus(defaults: UserDefaults = .standard, signedIn: Bool = CloudBackup.isSignedIn())`; Profile calls it in `.onAppear` and on `UIApplication.willEnterForegroundNotification`. `eraseAllData` sets `lastICloudWrite = nil` (the key is `pt_`, so the wipe clears it on disk).
   - `BackupStatus.rowValue(lastExport:iCloudWrite:iCloudSignedIn:sessions:now:calendar:locale:)` and `needsNudge(lastExport:iCloudWrite:sessions:)`. Rules:
     - The latest backup is the later of `lastExport` and `iCloudWrite`. The pending count and the nudge count sessions after that date (a weekly iCloud file is a backup).
     - pending >= threshold: `"<n> workouts not backed up"` (unchanged text).
     - Signed out: `"iCloud off · Exported Nov 3"`, or `"iCloud off · Never exported"` with no export.
     - Signed in, iCloud write is the latest: `"iCloud backup Nov 3"`. Export is the latest: `"Exported Nov 3"`. Neither: `"Never exported"`.
     - Same year-dropping date style as today.
   - Update the Profile Data row call site to pass the new state.
   - Update the `CloudBackup.swift` header comment: the Data row now reads both dates.
5. **Erase copy.** Append to the dialog message: " The weekly backup in iCloud Drive stays. Remove it in Settings > your name > iCloud > Manage Account Storage." Leave the button subtitle alone.
